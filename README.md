# Gourav Kumar Singh – Portfolio

React + Vite. Edit your content in `src/data.js`.

- Add your photo as `public/photo.jpg` (portrait, ~800×1000). Until then, initials show.
- Replace the resume at `public/Gourav_Singh_Resume.pdf` when you update it.

Run locally: `npm install && npm run dev`

Deploy on Vercel: push to GitHub → vercel.com/new → import the repo → Deploy.
(Vercel detects Vite automatically: build `npm run build`, output `dist`.)
